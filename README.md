## 一、项目概述与技术细节

- **技术栈**：
  - **核心框架**：React 18 + Vite + TypeScript
  - **样式与排版**：Tailwind CSS（采用温暖马卡龙/米黄柔和基底 `#FFE9C7` ~ `#FFD3A3`，全界面圆角微质感，针对手机端与桌面端全尺寸适配）
  - **动效引擎**：`motion/react`（Framer Motion）（负责卡牌翻转、摇晃蓄力、冲刺撞击打击感、震屏、伤害漂浮与弹窗平滑过渡）
  - **图标系统**：`lucide-react`
  - **音效系统**：基于 Web Audio API 纯原生合成音频（无外部音频资源依赖，内置击中、冲刺、治疗、胜利、失败等实时波形合成）
- **核心特色**：
  - **盲盒悬念**：BOSS 初始生命值与攻击力在战斗开始前完全隐藏。
  - **半血战况揭秘**：血量降至临界线时触发侦察情报，以环形仪表盘呈现双方实时百分比。
  - **防扰动时序保护**：回合严格依照“玩家行动 ➔ BOSS 反击 ➔ 回合结算 ➔ 检查警报弹窗”的时序执行，杜绝动画冲突与弹窗闪烁。

## 三、核心游戏规则与战斗机制

### 3.1 游戏流程阶段
1. **属性配置（Setup）**：设定勇士初始生命值、攻击力，也可配置随身补给食物等；
2. **抽取魔物（Draft）**：点击宝箱开启随机抽取 4 大魔物（木巨人、狼牙、巨斧、女巫）。**翻开卡片后可选择“开始决斗”、“重新抽取”，或直接点击“放弃挑战（逃跑判负）”**，放弃将直接以逃跑判负进入结算；
3. **回合对决（Battle）**：进入战斗舞台展开交锋，底栏常驻提供**普通攻击**、**使用补给**，以及**逃跑（逃跑后相当于失败）**按钮；
4. **战局结算（Result）**：击败魔物（大获全胜）、力战不敌（战败倒下）或逃跑/放弃（逃跑失败），汇总展示交锋回合、总输出/承受伤害及补给消耗。

### 3.2 回合交锋与逃跑机制
- 玩家每回合拥有优先选择权，可在以下三项行动中选择一项：
  1. **普通攻击**：勇士蓄力冲刺，对 BOSS 造成等同于玩家攻击力的直接伤害；
  2. **使用补给**：点击后弹出**补给背包弹窗**（仅显示拥有的补给），根据当前生命缺口选择具体的美食物品进行针对性回复；
  3. **战略逃跑**：底栏与半血面板均提供“逃跑”操作。**逃跑后直接判定为挑战失败（逃跑失败）**，即刻脱离战场进入结算。
- **放弃与逃跑判定**：
  - **抽取后放弃**：在魔物展示阶段点击“放弃挑战”，将判定为逃跑失败（0 回合，未开战即弃）；
  - **打斗中逃跑**：在战斗过程中点击“逃跑”，将判定为逃跑失败，并保留已进行的交锋数据与消耗明细；
  - 结算页面将统一展示逃跑落败专属警示徽章与失败结算。
- **BOSS 反击逻辑**：玩家行动完成后（无论攻击还是补给），若 BOSS 未死亡，BOSS 会必定发起反击冲刺。
- **伤害公式与暴击机制**：
  - **暴击判定**：玩家发起普通攻击时，按设定概率判定暴击（默认为 20%，可在高级对决规则中配置 0%~100%）；
  - **未暴击**：$Damage_{Player} = Attack_{Player}$
  - **触发暴击**：$Damage_{Player} = \text{round}(Attack_{Player} \times (1 + \text{CritBonus}))$，默认攻击力增加 200%（即造成 300% 伤害，支持在规则中自由调节加成）；
  - **暴击特效**：暴击触发时呈现强力震屏、显目「💥 暴击!」炽热浮空飘字、专属重击受击效果，结算时统计暴击次数；
  - BOSS 对玩家伤害：$Damage_{BOSS} = \text{round}(Attack_{BOSS} \times (1 + \Delta))$，其中 $\Delta \in [-\text{fluctuation}, +\text{fluctuation}]$
- **受击色彩规范**：
  - BOSS 受击：红色飘字（`-XX`）与暖红震屏；
  - 玩家受击：蓝色飘字（`-XX`）与受击微震；
  - 生命恢复：绿色飘字（`+XX`）与光环特效。

### 3.3 独立补给系统（Supply System）
- **动态选择弹窗**：点击“补给”时触发专门的物品选择弹窗，**仅展示勇士当前背包中拥有的物品（数量 > 0），未拥有或已耗尽的物品不予显示**，界面干净利落；同时实时显示勇士当前生命值与各物品使用后的预计恢复血量。
- **全新 9 种补给食物配置**：
  1. **🍞 面包**：回复 **2 HP**（日常便粮，垫肚子充饥）；
  2. **💧 水**：回复 **3 HP**（清凉甘泉，及时解渴润喉）；
  3. **🍪 饼干**：回复 **5 HP**（香脆点心，补充少许体力）；
  4. **🌭 火腿肠**：回复 **10 HP**（美味肉肠，咸香可口开胃）；
  5. **🥤 可乐**：回复 **12 HP**（活力汽水，迅速提神振奋）；
  6. **🥠 压缩饼干**：回复 **20 HP**（军工干粮，饱腹感强劲抗饿）；
  7. **🥮 月饼**：回复 **30 HP**（传统甜点，高糖高能快速回血）；
  8. **🥩 牛肉**：回复 **40 HP**（强力肉食，大口吃肉强健筋骨）；
  9. **⚡ 能量饮料**：回复 **70 HP**（特级秘药，极速焕发全身生机）。
- **背包与使用规则**：
  - **开始前自由配置**：在开始游戏前的属性设置页面中，用户可以自由添加自己所拥有的各种补给数量（默认均为 0 件，用户可任意加减设定）；
  - **使用次数不设限**：在对决中，**使用补给的次数不再有人为上限限制**，只要行囊中某食物尚有库存且血量未满，即可自由使用直到耗尽！
  - **结算精准提示**：游戏结束后，结算页面会明确统计并提示用户在本次战斗中**总共使用了多少件补给**，并附带详细的消耗清单明细。

### 3.4 半血战况揭示机制（Half-HP Reveal）
- **触发条件**：当玩家或 BOSS 的当前生命值首次降至总生命的 **50%（或自定义阈值）** 以下时触发。
- **时序保护（避免闪烁）**：
  - 若玩家攻击导致 BOSS 破半血，**不会在此瞬间立刻打断界面**，而是先让 BOSS 正常完成本回合的反击冲刺；
  - 待整回合双方伤害全部结算后，再向玩家弹出“战况警报·半血揭示”弹窗；
  - 弹窗内可直观查看双方当前百分比，并供玩家选择“继续攻击”、“使用补给”或“果断撤退”；
  - 弹窗操作具备防连击锁定（`isBusy` 保护），避免快速连续点击导致状态异常。
- **侦察次数上限**：最多进行 $1 + \text{maxExtraReveals}$ 次侦察提示（默认最多 3 次）。

## 五、游戏参数调整与配置指南

### 5.1 在游戏界面直接调整（免改代码）

在游戏首屏（勇士属性设定页），提供两层配置入口：

1. **基础属性设置**：
   - **生命值（HP）**：支持滑动条与快捷步进按钮或直接数字输入（范围：`100 ~ 5000+`，默认 `500`）。
   - **攻击力（ATK）**：支持滑动条与快捷步进按钮或直接数字输入（范围：`10 ~ 1000+`，默认 `100`）。
2. **随身补给行囊（Backpack）**：
   - **9 种补给物品自选**：包含面包(+2)、水(+3)、饼干(+5)、火腿肠(+10)、可乐(+12)、压缩饼干(+20)、月饼(+30)、牛肉(+40)、能量饮料(+70)。
   - **数量加减与直输**：默认均为 0，支持 `+` / `-` 步进及键盘直接输入（0~99）；
   - **快捷预设**：支持一键“全部清零”、“基础干粮包”、“全套备齐”。
3. **高级规则面板（点击展开）**：
   - **BOSS 攻击浮动率（Fluctuation）**：默认 `10%`（即实际攻击在 `90% ~ 110%` 随机波动，可在 `0% ~ 30%` 调整）。
   - **半血警报阈值（Threshold）**：默认 `50%`（可选 `30% ~ 60%`）。

### 5.2 在代码中修改默认参数与数值平衡

若想调整每次刷新页面后的**默认数值**或拓展限制，请编辑文件：
👉 **`/src/constants.ts`**

```typescript
export const DEFAULT_CONFIG: GameConfig = {
  playerHP: 100,            // 玩家默认初始生命值
  playerAttack: 20,         // 玩家默认攻击力
  bossFluctuation: 0.1,     // BOSS 攻击浮动率（0.1 = +/-10%）
  maxSupplies: 3,           // 默认携带补给包数量
  supplyHealAmount: 35,     // 每次使用补给包恢复的生命值点数
  halfHpThreshold: 0.5,     // 半血揭晓触发比例（0.5 = 50%）
  maxExtraReveals: 2,       // 额外侦察提示次数（1次初始 + 2次额外 = 共3次）
};
```
